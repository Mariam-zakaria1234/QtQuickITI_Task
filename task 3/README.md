# 🏠 Smart Home Control Panel UI

A modern, responsive, and dark-themed **Smart Home Dashboard** desktop application built using **Qt Quick (QML)**. This application features page navigation, device management, and detailed controls for individual smart home appliances.

---

## 🎯 Key Features

- **Multi-Screen Navigation:** Uses `StackView` to manage smooth screen transitions (Login ➔ Device List ➔ Settings).
- **Authentication View:** Modern login screen with styled `TextField` input elements and focus animations.
- **Scrollable Device Hub:** `ScrollView` container to browse through available smart appliances cleanly.
- **Device Controls:**
  - **Air Conditioner (AC):** Features power toggling, interactive target temperature slider, and step control buttons (`+` / `-`).
  - **Other Devices:** Dynamic control pages for Vacuum Cleaner, Smart Lights, Smart TV, and Washing Machine with interactive `Switch` toggles.
- **Sleek UI Design:** Dark-mode color palette (`Slate` / `Sky Blue`) with rounded cards, custom borders, and aligned layouts using QML Anchors & Positioning.
